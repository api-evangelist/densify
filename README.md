Densify — now trading as Kubex — provides a machine-learning driven cloud, GPU and container optimization platform that continuously right-sizes resources to cut cost and protect performance across Kubernetes, public cloud and GPU/AI infrastructure. The Kubex REST API publishes 65 operations across 21 first-party OpenAPI documents covering cloud account onboarding and analysis, AWS/Azure/GCP right-sizing recommendations, Kubernetes cluster and container recommendations, the system inventory, analysis webhooks and a customizable Subscriptions surface, so optimization can be embedded into CI/CD pipelines, Terraform and other infrastructure-as-code, and FinOps workflows. Kubex also ships a per-tenant Model Context Protocol server and publishes an A2A agent card and an Agent Skill from its documentation host.

**Areas:** Cloud Cost · Container Optimization · FinOps · Kubernetes · Machine Learning · Recommendations · Rightsizing · A2A

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Densify: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
